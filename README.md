# KaamSaathi (working title)

**A local-first work companion for Indian creators, freelancers, and small businesses.**

KaamSaathi is meant to help people explain a goal in everyday language, get a clear plan, and approve useful work across their selected projects. The product should be easy to understand, multilingual, accessible to older adults, and respectful of the user's device and data.

## What is in this repository now

This repository starts with a small, installable web prototype that demonstrates the task-planning experience. It supports project cards, a simple demo plan, step completion, an activity list, English/Hindi interface labels, a larger-text control, and browser-local saving.

**The current demo does not contain an AI model and cannot control your computer or phone.** Its sample plans are generated by simple rules so the product flow can be seen without an API, account, or server. No task data is sent to a backend.

## Open the demo

Open `index.html` in a browser. For install/offline behaviour, serve the folder as a static website over HTTPS (GitHub Pages can do this for a public repository) or use `localhost`. The demo data is stored in that browser's local storage. Clearing site data removes it.

## Product direction

The first real product should focus on one workflow: a user selects a project, assigns a goal, reviews the proposed steps, approves any changes, and sees a clear activity record. A Windows companion can later be the main local worker; Android can be a transparent task, status, and approval companion. A free connector can let the user's own projects pass context to the agent and receive feedback.

Read the product outline in [`docs/PRODUCT.md`](docs/PRODUCT.md), the system shape in [`docs/ARCHITECTURE.md`](docs/ARCHITECTURE.md), and the staged plan in [`docs/ROADMAP.md`](docs/ROADMAP.md).

## Distribution intention

- Windows build: Microsoft Store, after a real Windows app is implemented and reviewed.
- Android build: signed APK from GitHub Releases and the project website.
- Optional Android directory: Uptodown; PhonePe Appstore only if its terms still fit the project's no-cost requirement at release time.
- Google Play is outside this project's current distribution plan.

Those are release targets, not completed packages. This prototype is a static web app and is not yet an Android APK or a Windows desktop app.

## Cost and model boundary

The prototype uses no paid service. The intended personal edition runs an eligible open-weight model on the user's own device, so inference does not require a paid hosted model API. The exact model depends on device hardware and its licence. If we later add shared hosted AI, always-on cloud work, or public multi-user services, compute and storage will have to be paid by someone or kept within a provider's changing free limits.

## Safety and accessibility principles

- Work only in folders and projects the user selected.
- Show a visible active state, a pause control, and an activity history.
- Preview edits and ask before consequential actions.
- Keep a restore path for changed files.
- Use plain language, large text, keyboard support, and reviewed Indian-language translations.
- Never build hidden screen recording, keystroke logging, or stealth monitoring into the product.
